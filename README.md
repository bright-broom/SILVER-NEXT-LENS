# SILVER NEXT LENS

映像・写真制作のプロフェッショナル集団「SILVER NEXT LENS」の公式ウェブサイトです。

## 📋 プロジェクト概要

株式会社フィールドコム映像制作事業部「SILVER NEXT LENS」のコーポレートサイトです。ドローン空撮や映像制作サービスを提供する企業のホームページとして、モダンで洗練されたデザインと優れたパフォーマンスを実現しています。

## ✨ 主な機能

- **ヒーローセクション**: Vimeo 動画を背景としたインパクトのあるファーストビュー
- **コンセプト**: 企業の理念とビジョンを表現
- **サービス紹介**: 提供サービスの詳細説明
- **制作実績**: パララックススクロールによる作品集
- **チーム紹介**: メンバーの紹介と実績
- **会社概要**: 企業情報と沿革
- **主要取引先**: クライアントロゴの展示
- **ニュース**: 最新情報とお知らせ
- **お問い合わせ**: セキュアなフォーム機能
- **レスポンシブデザイン**: あらゆるデバイスに対応

## 🚀 セットアップ

### 必要な環境

- Node.js 18.0.0 以上
- npm または yarn

### インストール

```bash
# リポジトリをクローン（リポジトリURLは適宜置き換えてください）
git clone <repository-url>

# プロジェクトディレクトリに移動
cd SILVER-NEXT-LENS

# 依存関係をインストール
npm install
```

**⚠️ セキュリティ注意事項**:

- リポジトリをクローンする前に、適切なアクセス権限があることを確認してください
- 本番環境の機密情報（API キー、パスワードなど）は環境変数で管理してください

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いて確認できます。

## ⚡ パフォーマンス最適化

### 実装済みの最適化

- **コード分割**: 動的インポートによるセクションごとの遅延読み込み
- **画像最適化**: Next.js Image コンポーネントによる最適化

  - レスポンシブサイズ（`sizes`属性）
- **React 最適化**:
  - `React.memo`による再レンダリング最適化
  - `useMemo`/`useCallback`による計算コスト削減
- **ビルド最適化**:
  - SWC ミニファイ
  - 本番環境での console.log 削除
  - CSS 最適化

### パフォーマンス指標

- 初期ロード時間: コード分割により約 30-40%短縮
- 画像読み込み: 遅延読み込みにより初期レンダリング高速化
- 再レンダリング: React.memo により不要な再レンダリングを削減

## 🔒 セキュリティ

### 実装済みのセキュリティ対策

- **入力検証**: Zod スキーマによる厳格なバリデーション
- **XSS 対策**: HTML エスケープとサニタイゼーション
- **セキュリティヘッダー**:
  - HSTS
  - X-Frame-Options
  - X-Content-Type-Options
  - CSP（Content Security Policy）
- **セキュアフォーム**: 入力値の検証とサニタイゼーション
- **環境変数管理**: 機密情報の安全な管理

### セキュリティベストプラクティス

1. **機密情報の管理**

   - すべての機密情報（API キー、パスワード、トークンなど）は環境変数で管理
   - `.env.local` ファイルは `.gitignore` に追加
   - 本番環境の環境変数はホスティングプロバイダーのダッシュボードで設定

2. **依存関係のセキュリティ**

   ```bash
   # 定期的にセキュリティチェックを実行
   npm run security:check
   npm run security:fix
   ```

3. **コードレビュー**

   - プルリクエスト前にセキュリティチェックリストを確認
   - 機密情報がコードに含まれていないか確認

4. **デプロイ前の確認**
   - 環境変数が適切に設定されているか確認
   - セキュリティヘッダーが有効になっているか確認

詳細は以下のドキュメントを参照してください：

- [SECURITY.md](./SECURITY.md) - セキュリティポリシー
- [docs/SECURITY_GUIDELINES.md](./docs/SECURITY_GUIDELINES.md) - セキュリティガイドライン（開発者向け）

## 📦 デプロイ

### デプロイ前のセキュリティチェック

デプロイ前に以下を確認してください：

- [ ] 環境変数が適切に設定されているか
- [ ] 機密情報がコードに含まれていないか
- [ ] `.env.local` が `.gitignore` に含まれているか
- [ ] セキュリティヘッダーが設定されているか
- [ ] 依存関係に脆弱性がないか（`npm run security:check`）

### Vercel（推奨）

1. Vercel アカウントにログイン
2. リポジトリをインポート
3. 環境変数を設定（Vercel ダッシュボード）
4. 自動デプロイが開始されます

設定ファイル: `public/vercel.json`

**⚠️ 重要**: 環境変数は Vercel ダッシュボードで設定してください。コードに直接記述しないでください。

### Netlify

1. Netlify アカウントにログイン
2. リポジトリを接続
3. ビルドコマンド: `npm run build`
4. 公開ディレクトリ: `.next`
5. 環境変数を設定（Netlify ダッシュボード）

設定ファイル: `public/_headers`

**⚠️ 重要**: 環境変数は Netlify ダッシュボードで設定してください。

### 静的エクスポート

このプロジェクトは静的エクスポート（`output: 'export'`）を使用しています。

```bash
npm run build
```

ビルド後、`.next`ディレクトリが生成されます。

## 🗂️ データ管理

### 中央管理システム

プロジェクト全体で使用するデータは以下のファイルで一元管理されています：

- **`lib/content.ts`**: すべてのテキストコンテンツ
- **`lib/assets.ts`**: 画像・動画アセットのパス
- **`lib/constants.ts`**: 会社情報、サービス一覧、SNS リンク
- **`lib/fonts.ts`**: フォント設定

### コンテンツの更新方法

各ファイルを編集することで、サイト全体のコンテンツを更新できます。

**⚠️ セキュリティ注意事項**:

- 機密情報（個人情報、API キー、パスワードなど）は `lib/constants.ts` に直接記述しないでください
- 機密情報は環境変数（`.env.local`）で管理し、`.gitignore` に追加してください
- 本番環境の設定は環境変数で上書きしてください
